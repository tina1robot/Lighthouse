## Projects Summary

### P1: Dirty Dog Labs Network Analysis
Assessment of a virtualized lab environment with Windows 11, Kali Linux, and Ubuntu servers. Identified network topology, enumerated services using Nmap, and analyzed network traffic with Wireshark. Provided security recommendations including firewall implementation, VLAN segmentation, and service hardening based on identified vulnerabilities.

### P2: Big Dog Risk Assessment
Comprehensive risk analysis for an enterprise environment. Evaluated current security posture, prioritized vulnerabilities by business impact, and developed remediation roadmap with cost-benefit analysis. Created executive presentation for leadership review, demonstrating ability to communicate technical findings to non-technical stakeholders.

### P3: Turn a New Leaf Log Monitoring
Designed and implemented an automated log monitoring workflow for a non-profit organization supporting youth job search initiatives. Created a Bash-based backup system to ensure log file redundancy and protection, developed a Python log analyzer to detect error patterns and failed login attempts, and established automated email reporting to send findings to senior management. The solution streamlines security monitoring by eliminating the need for manual log file review and reduces human error in identifying potential security incidents. Features include detection of multiple failed login attempts indicative of brute force attacks and system error flagging for compliance and investigation purposes.

### P4: Cybersecurity Response Playbook (Cat in Box)
Companion document to incident response training containing operational procedures and communication templates for incident response. Includes detailed workflows for detection, analysis, containment, remediation, recovery, and post-incident review phases. Provides structured guidance for phishing attack response, role definitions for incident response teams, and escalation procedures for various threat levels.
